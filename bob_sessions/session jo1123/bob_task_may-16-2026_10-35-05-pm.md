**Purpose**: Manages JWT refresh tokens for user authentication

**Function**:

- Enables token rotation and secure re-authentication without requiring password re-entry
- Tracks token expiration for security
- Each token is linked to a specific user

**Key Fields**:
- `user_id`: Links to the users table
- `token_hash`: Hashed version of the refresh token (not stored in plain text)
- `expires_at`: Expiration timestamp for token validity
- Cascades deletion when user is deleted
- Has index on `user_id` for fast lookups (line 275-276)
