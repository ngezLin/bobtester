🎬 Install BobTester Recorder

One-click automated test recording for your browser

🌐
Chrome / Edge
🦊
Firefox
1 Download Extension
Click the button below to download the extension as a ZIP file.
2 Extract the ZIP File
Extract the downloaded ZIP file to a permanent location on your computer (e.g., Documents/BobTester). Don't delete this folder - the extension needs it to run.
3 Open Extensions Page
Open chrome://extensions/ in your browser, or click the button below:
4 Enable Developer Mode
Toggle the "Developer mode" switch in the top-right corner of the extensions page.
5 Load the Extension
Click "Load unpacked" and select the extracted extension folder.
6 Pin to Toolbar
Click the puzzle icon in your browser toolbar and pin the BobTester Recorder extension for easy access.
